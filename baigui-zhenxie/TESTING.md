# 百鬼镇邪 · 首版实测

测试日期为 2026-11-26 UTC。逻辑使用 Node 24，界面使用 Chromium 156.0.8078.79 与 Playwright。浏览器加载静态发布文件，实际执行 JavaScript、Canvas 绘制、音频解码、键鼠和 CDP 多点触控。运行原始记录见 [规则结果](tests/rules-results.txt) 和 [浏览器结果](tests/browser-results.json)。

## 压力测试与修复

移动视口 390×844，Chromium 模拟四倍 CPU 降速，布置 58 个存活鬼物。初测约 13 FPS。修复后使用低帧率触发的动态画布分辨率、缓存镜像精灵、简化远景光照与高密度阴影。同一负载复测平均 50.3 FPS，95 百分位帧间隔 33.4 ms，共 93 个帧间隔样本，画布像素比降至 0.82。碰撞、伤害和攻击预警仍使用同一套模拟与几何范围。

优化前还修复了竖屏封面人物面部被裁切、320 像素宽时的触控键位间距，以及短时间鼠标点击可能在两帧之间丢失普攻的问题。

## 已知限制

- 触屏和降速测试在 Chromium 模拟器中完成。iOS Safari、实体低配 Android 的帧率、音频和长时发热待实机确认。
- 战斗精灵使用少量动作关键姿势结合程序过渡。角色转向使用左右镜像。
- 画面高负载时主动降低内部渲染分辨率，边缘和小精灵会变柔。连续高负载效果与更大的地图有待继续压测。
- 当前进度按单局结算。术法、装备在重开时重置，同一浏览器会保留最高镇伏数。
