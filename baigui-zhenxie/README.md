# 百鬼镇邪 · 雾隐村

《百鬼镇邪》是一个原创暗黑国风 2.5D 动作 RPG。年轻术士沈砚携桃木剑和离火符入村。击倒鬼物、收取鬼魄、参悟术法，守过三更后迎战铜面祠君。

**[网页试玩](https://kelvinhii67.github.io/game/baigui-zhenxie/dist/)** · [实测报告](TESTING.md) · [美术与音效](ASSETS.md)

## 操作

| 动作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 左侧虚拟摇杆 |
| 桃木剑三连击 | 左键朝指针出剑，长按 J 自动朝近敌出剑 | 轻点或长按桃木剑 |
| 闪避 | 空格，按当前移动方向闪避 | 点闪避，可同时推动摇杆 |
| 施法 | Q / E / R / F / C，也可按 1–5 | 点术法图标 |
| 行囊和暂停 | Tab / Esc | 屏幕右上方按钮 |
| 选择强化 | 鼠标点击，或按 1–3 | 点击强化卡片 |

靠近鬼魄和物品即可拾取。升级时从随机三项中选一项，同一术法升至第三阶会新增机制。法剑提高普攻伤害，法衣降低受到的伤害，佩玉提高术法伤害。装备分凡、灵、玄、珍四品。更高品质自动穿戴，行囊里可以换回其他装备。

| 术法 | 定位 | 第三阶 |
| --- | --- | --- |
| 折将纸扎 | 自主近战纸兵 | 三纸兵出阵，攻击波及邻敌 |
| 引灯御鬼 | 绕身幽魂，飞袭挂鬼火印 | 双幽魂同时出击 |
| 离火符箓 | 远程符弹、爆炸与燃烧 | 三道离火符扇形射出 |
| 紫垣雷法 | 爆发、连锁，消耗鬼火印增加伤害 | 连锁后重击首敌 |
| 缚阴地阵 | 地面减速、持续灼伤 | 布阵时把附近小怪拉向阵眼 |

铜面祠君第一阶段依次施放落印、直线劈斩和扇形斩击。气血降至 55% 后破面，布下留有内圈安全区的逆阴环，继而使用交叉斩、双落印和更短的预警。击败祠君完成单局，倒地后可立刻重来。结算将最高镇伏数保存在当前浏览器。

## 本地运行与部署

游戏是零运行时依赖的静态网页。将 `dist/` 作为静态站点目录发布即可，支持子路径部署。下载静态包后，在解压目录启动 HTTP 服务。

```sh
python3 -m http.server 8000 --directory dist
```

浏览器打开 [http://localhost:8000/](http://localhost:8000/)。音频由第一次点击解锁，服务器需要按文件扩展名提供 MIME 类型。

仓库已配置从 `main` 根目录发布 GitHub Pages。本游戏位于 `baigui-zhenxie/`，根目录为仓库中原有的另一款游戏。

## 源码

- `dist/index.html` 与 `dist/game.css` 是封面、状态栏和触屏界面。
- `dist/rules.js` 是固定 60 Hz 的战斗、波次、装备和成长模拟。
- `dist/render.js` 是按脚点排序的 Canvas 场景、精灵动画、光影、攻击预警与术法特效。
- `dist/game.js` 负责键鼠和多点触控、音频、HUD、菜单与单局状态。
- `dist/assets/` 是所有游戏运行资产，`art-src/` 保留原始美术图集，`tools/` 包含资产处理与原创音效合成脚本。
- `tests/` 包含数值模拟、Chromium 自动化和实测输出，`screenshots/` 保留浏览器界面截图。

## 复测

```sh
node tests/rules.test.cjs
npm install --no-save --no-package-lock playwright
CHROMIUM_PATH=/usr/bin/chromium node tests/browser.cjs
```

自动化可通过 `PLAYWRIGHT_MODULE` 指向已有 Playwright。设置 `WUYIN_URL` 后可用相同脚本复测静态部署地址。使用 Chrome 或 Chromium 替换 `CHROMIUM_PATH`，无需服务端游戏逻辑。
