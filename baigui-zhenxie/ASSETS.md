# 美术与音效

美术使用 Codex 环境内置图像生成工具制作。创作先确定沈砚的束发、深蓝道袍、米白领口、朱砂腰带和桃木剑，再据同一设定制作封面、战斗动作和图标。动作补图以角色图集作为参考，铜面祠君的破面形态以原形为参考。

| 原图 | 游戏内用途 |
| --- | --- |
| `art-src/cover.png` | 封面立绘、雾隐村背景与 HUD 头像 |
| `art-src/map.png` | 雾隐村祠堂、房屋、湿石板、八卦嵌线、灯笼与供物 |
| `art-src/sprites.png` | 沈砚待机、奔跑、挥剑和施法，纸人、亡魂、僵尸和铜面祠君 |
| `art-src/motion.png` | 沈砚第二奔跑姿势、第三剑收招、受击后仰和倒地 |
| `art-src/boss-break.png` | 破面后露出邪火面孔的铜面祠君 |
| `art-src/icons.png` | 五门术法、法剑、法衣、佩玉与回阳散 |

`tools/prepare-art.py` 使用 Pillow 裁切透明图集并导出 WebP。Canvas 按各姿态的脚点校准坐标，用左右镜像、跑步交替姿态、倾斜、施法过渡、闪避残影和受击闪白衔接动作。鬼物按类型使用步态、悬浮、攻击蓄势、击退和消亡动画。石板场景上叠加灯笼光晕、地面阴影、流雾、浮尘和第二阶段的暖红光。

原创音乐与十五个音效由 `tools/make-audio.py` 合成。配乐由低持续音、五声音阶钟音与风噪构成。挥剑、命中、闪避、施法、爆破、受击、掉落、升级与 Boss 事件各有声音。脚本通过 FFmpeg 输出 Ogg Vorbis 和 AAC，浏览器按支持情况选用。运行时直接从本地站点读取音频与美术，无第三方资产请求。
